## Overview

Cashier System sits next to the loyalty program. Cashiers validate and apply rewards at checkout, and the loyalty balance stays in sync.

## What I built

- Redemption by coupon code or balance check at the point of sale.
- Synchronization with the loyalty backend so points update when a reward is used.
- API integration to validate, apply, and update redeemed rewards.
- Cashier interface with Angular, TypeScript, and Bootstrap.

## Stack

Angular, TypeScript, Bootstrap, CSS, REST APIs.
