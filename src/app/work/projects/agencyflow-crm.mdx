## Overview

AgencyFlow CRM is a platform for running an agency: sales, client delivery, finance, and team operations in one place. I built the product with Next.js, React, TypeScript, FastAPI, and PostgreSQL.

## What I built

- Kanban pipelines for leads, deals, clients, and projects.
- GST invoicing and financial reporting so billing stays inside the same workflow as delivery.
- Responsive dashboards and reusable UI components for day-to-day operations.
- Frontend integration with backend APIs and PostgreSQL for persistent business data.

## Stack

Next.js, React.js, TypeScript, FastAPI, PostgreSQL.
