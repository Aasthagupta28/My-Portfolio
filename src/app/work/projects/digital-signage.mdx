## Overview

Digital Signage is a frontend for managing media on display screens from one place. Organizations use it to schedule content and control how that content plays.

## What I built

- Responsive interface for centralized media content management.
- Scheduling, playlists, and portrait or landscape display support.
- API integration for screen and media management.

## Stack

Angular, TypeScript, Bootstrap, REST APIs.
