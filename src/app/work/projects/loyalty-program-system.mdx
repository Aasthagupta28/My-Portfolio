## Overview

Loyalty Program System lets restaurants register and run customer loyalty campaigns. Rewards can be based on order value or how often a customer orders.

## What I built

- Loyalty program flows that assign rewards from order value or frequency.
- Rules for points, coupon generation, and reward distribution.
- Campaigns that send coupon codes for later orders.
- Angular, TypeScript, and Bootstrap UI, integrated with REST APIs for registration, orders, points, and redemption.

## Stack

Angular, TypeScript, Bootstrap, CSS, REST APIs.
