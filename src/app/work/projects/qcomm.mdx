## Overview

QComm and QComm Client are the admin and display sides of an enterprise alert system. Operators send alerts, and client screens present them. I built the frontend applications and the modules that deliver those alerts.

## What I built

- Frontend applications with Angular, JavaScript, Bootstrap, and TypeScript.
- Real-time alert modules: popup, video, quiz, and message.
- API integration for alert delivery and client-side alert management.
- Responsive UI so alerts stay readable across devices.

## Stack

Angular, TypeScript, JavaScript, Bootstrap, REST APIs.
