## Overview

This project customized Payload CMS for an enterprise content workflow. I connected the CMS to a Next.js admin experience and NestJS APIs, with PostgreSQL as the content store.

## What I built

- Payload CMS customization and integration.
- Next.js admin panel for editors.
- NestJS APIs for content delivery.
- Content handling, translations, and a PostgreSQL-based CMS architecture.

## Stack

Payload CMS, Next.js, NestJS, PostgreSQL.
