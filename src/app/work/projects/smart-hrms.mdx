## Overview

Smart HRMS is a full-stack human resource system. I built it so HR teams can manage people, attendance, leave, and hiring from one role-aware product.

## What I built

- Role-based application structure using Next.js, React, Tailwind CSS, Django, and Python.
- Employee, attendance, leave, and recruitment modules.
- Responsive dashboards connected to secure APIs.

## Stack

Next.js, React, Tailwind CSS, Django, Python.
