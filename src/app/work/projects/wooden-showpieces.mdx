## Overview

Wooden Showpieces is an eCommerce application for a product catalog and online shopping. I built the storefront and the application flow that connects the interface to the backend.

## What I built

- Full-stack store using Next.js, React, Django, and Tailwind CSS.
- Responsive product pages.
- Shopping workflows for browsing and purchasing products.

Next.js, React, Django, Tailwind CSS.
