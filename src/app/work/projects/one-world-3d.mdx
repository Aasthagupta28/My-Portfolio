## Overview

One World 3D is a global production platform that helps teams turn written stories into AI-assisted production plans and media. I built scalable frontend interfaces and contributed to the workflows that parse scripts and plan production.

## What I built

- Scalable interfaces with Next.js, React, and Tailwind CSS.
- Script-parsing and production-planning workflows using Django, React, and Celery.
- Integrations with OpenAI and fal.ai for text, voice, video, and 3D asset generation.

## Stack

Next.js, React, Tailwind CSS, Django, Celery, OpenAI API, fal.ai.
